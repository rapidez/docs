# Artificial Intelligence

---

Do you want to build your next webshop with AI? Most of the AI agents around know what Rapidez is and how it works, but you can help them with these instructions.

[[toc]]

## Laravel Boost

> Laravel Boost accelerates AI-assisted development by providing the essential guidelines and agent skills that help AI agents write high-quality Laravel applications that adhere to Laravel best practices.

Just follow the installation instructions in the [Laravel Boost docs](https://laravel.com/docs/boost). Rapidez packages include additional instructions which will be discovered by Laravel Boost automatically.

## Docs

AI agents can read these docs easier with `llms.txt` files. For the latest Rapidez version:

- https://docs.rapidez.io/llms.txt
- https://docs.rapidez.io/llms-full.txt

Or version specific:

- https://docs.rapidez.io/5.x/llms.txt
- https://docs.rapidez.io/5.x/llms-full.txt

::: tip FYI
With Laravel Boost installed the Rapidez docs will be discovered and used automatically!
:::

## Updates

Are you updating from Rapidez 4.x to 5.x? We do have a [prompt in the upgrade docs](upgrading.md#using-ai) which can help you to let AI do the upgrade automatically.
